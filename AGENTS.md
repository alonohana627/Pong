# Notes for coding agents

Pong is the first game built on GameLib (`../GameLib`, a separate repository).
It is GameLib's acceptance test: if Pong needs a general mechanism GameLib
lacks, the mechanism goes into GameLib (with tests) and Pong uses it; Pong's
own rules, look and sounds stay here.

## Ground rules

- Consume GameLib only through its CMake targets (`GameLib::core`,
  `GameLib::app`, ...) and public headers (`<gamelib/...>`). Never copy GameLib
  sources into this repository or include its `src/` files.
- Snake and Tetris (`C:\Users\user\Snake`, `C:\Users\user\Tetris`) are
  read-only references. Never modify them.
- Every visual is generated by shaders (GameLib built-in shapes or Pong's own
  shaders in `shaders/`). No image files.
- Audio goes through GameLib's miniaudio player; sounds are synthesized.
- `src/game` (rules and AI) depends only on `GameLib::core`: no window, GPU,
  audio or clock, so every rule is unit-tested headless.
- Zero compiler warnings, zero shader warnings, zero Vulkan validation
  messages (the smoke tests enforce the last one).
- Small Conventional Commits after each step that builds and passes its
  tests. Stage files explicitly; never commit build output. Never rewrite
  history. When a change spans GameLib and Pong, commit GameLib first, then
  Pong, and record the GameLib revision in `docs/GAMELIB_REVISION.md`.
- `FEATURES.md` lists what Pong does today: update it in the same commit as
  each implemented feature; never list planned work.

## Skill suggestions

Keep `SKILL_SUGGESTIONS.md` up to date: at the start of a session list
`~/.claude/skills/` and move newly installed skills to "Already installed";
add or sharpen an entry (kebab-case name, one paragraph, a "Why") whenever a
task would have gone better with a missing skill. Mention changes in one line.

## Commands

```powershell
cmake --preset debug           # configure (fetches ../GameLib via FetchContent)
cmake --build --preset debug
ctest --preset debug           # gameplay tests + smoke runs
ctest --preset debug-headless  # gameplay tests only
```
